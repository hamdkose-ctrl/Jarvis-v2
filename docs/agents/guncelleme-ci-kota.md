## Merkezi router deneme bütçesi — 9 Kasım 2026

- Yeni çağrı sözleşmesi `smart_router.ModelRequest`, `ModelSpec`, `RoutePlan` ve `RouteResult` tiplerini kullanır. Çağıran gerekli özellikleri, çıktı üst sınırını, deadline/iptali ve rotayı bildirir; router açık aday planını kurar. Prompt içeriğinden niyet, görev türü veya model kalitesi tahmini yapılmaz.
- `run_request` en fazla **iki üretim adapter denemesi** yapar; yerel model keşif istekleri bu sayaçta değildir. Hatalı şema yanıtı da başarısız denemedir; provider fallback veya tekrar için ayrı bir sayaç yoktur. Adapter geç yanıtı routerın `requests_state.check()` denetiminden sonra ancak kabul edilir; deadline/iptal edilmiş yanıt kullanılmaz. Fiziksel HTTP iptali garanti edilmez.
- Router üzerinden geçen metin çağrısında Gemini/Groq/Ollama taşıyıcıları seçilen tek modeli çağırır. Açık yerel seçim ve görüntü gibi doğrudan/uyumluluk yolları ayrıca sürer; bunlarda aynı seçim ve deneme bütçesinin tümüyle birleştiği iddia edilmez.
- **#540 resmî model kapasite kayıtları (9 Kasım):** Groq resmî model kartlarında `openai/gpt-oss-120b` ve `openai/gpt-oss-20b` için context 131.072, maksimum çıktı 65.536 token olarak belirtiliyor. Tam model ID + resmî HTTPS kaynağıyla **yalnız context/output** verisi geliştirici kataloğuna alındı, 16 Kasım 2026'da yeniden doğrulama olmadan zaman aşımına uğrayacak. Groq native schema API'si ayrı entegrasyon gerektirdiğinden **native_json_schema veya native_tool_calling iddiası eklenmedi**. Resmî kota tablosu hesap/organizasyon istisnaları içerebildiği için bu bilgi RPM/RPD rezervasyonuna kaynak sayılamaz; `router_quota.POLICIES` boş kalır.
- **#540 atomik yerel istek rezervasyonu:** `router_quota.reserve` yalnız geliştiricinin resmi kaynak, doğrulama tarihi ve exact provider/model ID ile kodda tanımladığı RPM/RPD için owner bazında `SQLite BEGIN IMMEDIATE` rezervasyonu yapar. Ayrı Windows process'leri aynı kota diliminde tek transaction ile yarışır; ağ isteği öncesinde kota bitmişse bu model atlanır. 60 sn/24 saat **kayan pencere** resmî reset saatinden daha katıdır. Bozuk veya süresi geçmiş *tanımlı* politika ile kilitli veritabanı ağ çağrısını engeller. `POLICIES` varsayılanı boş: hiçbir sağlayıcı limiti tahmin edilmez. Free-tier/billing hard-stop kanıtı ayrıca zorunludur. TPM/TPD için yalnız güvenilir input+max-output üst sınırı verilirse aynı rezervasyon uygulanabilir; neuron ve proje toplamı kapsam dışıdır. Boş `POLICIES` ile bu sınırların hiçbiri etkin değildir.
- **#540 native model yetenekleri:** Yeni `model_capabilities.CATALOG` kaynağı, yalnız geliştirici tarafından resmi kaynağı ve son kullanma zamanı doğrulanarak yazılabilecek, **tam sağlayıcı+model ID** eşleşmesidir. Yalnız iki Groq modeli için context ve çıktı sınırı kayıtlıdır; native JSON schema, native tool calling veya doğrulanmış vision kaydı yoktur. `ModelRequest.native_features` / `min_context_tokens` ileri gereksinimleri eksik, yanlış veya süresi geçmiş kanıtta provider adapter'a ulaşmadan eler. Eski `structured_output` uygulama tarafı validator anlamını korur; native şema desteği iddiası değildir. `ModelSpec.context_limit` yalnız geçerli kanıttan gelir. Bu **model bazlı doğrulama kapısı**dır, bütün sağlayıcıların canlı envanterinin tamamlandığı iddiası değildir.
- **#540 Groq gözlemlenen kota sıfırı:** Yalnız bu kullanıcı+provider+model için en son kaydedilmiş, zaman damgalı `x-ratelimit-remaining-requests/tokens=0` ve geçerli duration tipli reset başlığı varsa Router o modeli reset anına kadar atlar. Boş/bozuk/eski/eksik başlıklar kota kanıtı üretmez; ücretsiz hesap/evidence kapısı aynen geçerlidir. Kullanıcı veya model birbirinin header'ını tüketmez. Bu mekanizma **atomik RPM/RPD/TPM/TPD/neuron rezervasyonu değildir**; yalnız gereksiz 429 denemesini azaltan deny-only gözlemdir. Ağsız zaman, owner izolasyon ve policy regresyonları ekli.
- **#540 Cloudflare süre sınırı:** Taşıma soket timeout'ları `requests_state.budget_remaining()` ile kalan istek süresini aşmaz; ağ gönderiminden önce `requests_state.check()` uygulanır. Süresi dolduktan sonra gelen 200 yanıt kullanım sayacına yazılır ama kullanıcıya benimsenmez. Gerçek fiziksel HTTP durdurma/atomik rezervasyon garantisi değildir. Sahte HTTP oturumuyla no-send ve late-response regresyonları vardır.
- **#540 Cloudflare HTTP sayacı:** `cloudflare_chat.chat` yalnız gerçek `post` denemesinden sonra, HTTP durumuna göre (`ok`, `429`, `401`, `bozuk`, `bos` veya bağlantı hatası) tam bir `usage_meter.record` yazar. Kullanıcı slug'ı ve seçili model kullanılır; veri/anahtar/gövde kaydedilmez. Bağlantı öncesi eksik anahtar/boş istek kotadan düşmez. Bu sayaç canlı neuron rezervasyonu değildir; provider kota sınırları hâlâ kaynak doğrulamalı olmalıdır.
- **#540 gerçek SDK isteği (9 Kasım):** Gemini istemcileri (başlangıç, key değişimi ve kullanıcıya özel cache) `retry_options.attempts=1` ile kuruluyor; SDK'nın dahili retry'sı Router'ın iki fiziksel deneme bütçesini aşamaz. Destekleyen SDK'da otomatik continuation kapalı; API config bu alanı içermiyorsa eklenmiyor. Routed Gemini HTTP hata çağrısı da sonuç koduyla tek defa `usage_meter.record`'a yazılıyor; doğrudan legacy Gemini model döngüsü zaten saydığı için çift kayıt yapılmıyor. Bu yalnız Gemini taşıma/deneme muhasebesini kapatır; özel sağlayıcı UI, atomik rezervasyon, çoklu process kota ve model yetenek envanteri hâlâ açık; gerçek PC/Brain Full kanıtı değildir.

- Test izolasyonu: `test_execution_policy_stability` hem DNS hem çevrimdışı mesajını kontrollü ağ durumuyla doğrular. `test_publish_batch` STATE ve PR_STATE için aynı temizlenen geçici klasörü kullanır; kullanıcının `.jarvis` verisine yazmaz. Üretim davranışı değişmez.
