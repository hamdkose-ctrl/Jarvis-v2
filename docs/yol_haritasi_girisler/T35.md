# T35 — Telefon HTTPS kurulumu gerçekten bağlandı (B3)

- **Soru:** B3 telefon eşleştirmesi "Tailscale HTTPS'i kullanıcı açsın" diye bekliyordu. Oysa `phone.https_set(y)` kodda vardı ve **hiçbir çağıranı yoktu** — Jarvis kurulumu hiç denemiyor, kullanıcıya da ne yapacağını söylemiyordu.
- **Değişiklik:** `phone.https_setup(port, consent=..., on=...)` — açık izin yoksa çalışmaz; port aralığını doğrular; başarıda HTTPS adresini, başarısızlıkta Tailscale'in gerekçesini döndürür.
- **Komut:** `telefon https kur` / `telefon https kapat`. Kullanıcının komutu kendisi yazması izin sayılır; arka planda sessiz kurulum yok. Kurulum başarısızsa hesabın HTTPS'i etkin olmadığını söyler, kendi başına hesap açmaz.
- **Ölçülen:** `tests/test_phone_https_setup.py` 5/5 OK — izinsiz reddedilir, geçersiz port (0/80/70000/'8765'/True) reddedilir, başarılı kurulum URL döndürür, başarısız kurulum gerekçe döndürür, komut doğru izinle çağırır. Mimari denetim OK.
- **Dürüst sınır:** Gerçek `tailscale serve` çağrısı bu testlerde taklit edildi; canlı etki kullanıcı `telefon https kur` yazdığında ölçülecek. Tailscale kurulu değilse kurulum yine başarısız olur ve bunu söyler.
